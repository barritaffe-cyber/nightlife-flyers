# Integration

1. Run `interpretCocoScene` before CreativeBrief.
2. Add `scene` to concept picker input.
3. Composition consumes `toCompositionAuthority(scene)`.
4. Typography consumes `toTypographyAuthority(scene)`.
5. Palette consumes `toPaletteAuthority(scene)`.
6. Effects consumes `toEffectsAuthority(scene)`.
7. Renderer rejects overlap above each protection zone's allowance.
8. Art director treats hard constraint violations as blockers.
