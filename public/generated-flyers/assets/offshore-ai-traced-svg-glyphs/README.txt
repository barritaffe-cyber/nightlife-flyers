OFFSHORE AI-TRACED SVG GLYPHS
================================

These SVGs are NOT generated from a regular font.

They were traced directly from the AI-generated white-background typography specimen,
so A-Z and 0-9 preserve the visible AI letter silhouettes much more closely.

Included:
- A.svg through Z.svg
- 0.svg through 9.svg
- O-palm.svg           custom second O from OFFSHORE with palm motif
- OFFSHORE-wordmark.svg exact traced headline wordmark
- preview-sheet.svg

All glyphs use:
    fill="currentColor"

So Coco can use CSS color:
    color: #083f58;

Or inline the SVG and replace currentColor with a gradient / image pattern.

Note:
Vector tracing preserves the silhouette. The ocean/cloud photographic texture from the
specimen is intentionally not baked into each glyph, so Coco can apply its own fill.
