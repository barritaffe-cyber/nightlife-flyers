# Integration

1. Run Scene Interpreter.
2. Pass scene and event into `directCocoCreativeConcept`.
3. Pass the winner through adapters to Composition, Copy, Typography, Palette, and Effects.
4. Build one immutable render model.
5. Render preview and export from the same model.
6. Run compliance before export.

The renderer must not change placement, hierarchy, copy merging, signature move, palette roles, or effect intensity.
